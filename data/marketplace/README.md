# Marketplace Dataset

## Purpose

This dataset stores periodic marketplace floor prices for important Axie Infinity assets.

The objective is to support:

- Marketplace Intelligence
- ROI Analysis
- Investment Decision Support
- Cost-per-Daily-Slip calculations
- Machine Learning experiments
- Historical price tracking

## Collection Schedule

Normally collected every **Wednesday (Finance Day)**.

Additional snapshots may be recorded whenever significant market events occur.

## Categories

- Collectible Axies
- Land Items
- Accessories
- Consumables

Only marketplace floor prices are recorded.
