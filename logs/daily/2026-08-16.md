# 9. Data Architecture Decisions

## 9.1 NFT Identification

Axies must be identified using the immutable:

**Axie / NFT number (`asset_id`)**

Do not use mutable Axie names as primary identifiers.

Reason:

Axie names can be changed by owners, while the NFT number remains tied to the blockchain asset.

---

## 9.2 Marketplace Accounting

Marketplace transaction records should distinguish:

* Gross purchase / sale value
* Marketplace fee
* Net proceeds
* Gas
* Bounty Points earned
* Inventory recovery
* Trading P/L

Gas paid in RON should not be mixed directly into WETH trading P/L.

---

## 9.3 Bounty Economics

A bounty purchase should not be evaluated based only on:

`purchase_price`

The model should consider:

```text
Net Bounty Value
+ Expected Resale / Release Recovery
+ Other Task Coverage
- Marketplace Fees
- Gas
- Consumable Cost
- Reroll / Slip Cost
```

This becomes the basis for determining the **true economic cost of earning BP**.
