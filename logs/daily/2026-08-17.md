This reinforces an important AxieOS rule:

> **A recoverable bounty purchase is not economically free even when it can immediately be resold near the acquisition price.**

The optimizer must calculate:

`Net Recovery = Gross Resale - Marketplace Fee`

rather than comparing headline purchase and resale prices alone.

RON gas should continue to be tracked separately from WETH trading P/L.

# 13. Important Data / Model Decisions

## 13.1 Current Rank Strategy

Do not optimize exclusively for maximum BP.

Current optimizer strategy should balance:

```text
BP
+ Weekly Rank Value
+ Fortune Slip Preservation
+ Marketplace Recovery
+ Inventory Consumption
+ Gas
+ Marketplace Fees
```

The current operating strategy is best described as:

**Conserve / Top-500-first**

---

## 13.2 Low-BP Reroll Rule

Current user policy:

```text
if bounty_bp < 100:
    reroll
```

Subject to future optimizer exceptions for unusually strong task overlap or economic utility.

---

## 13.3 Marketplace Recovery

For bounty purchases:

```text
gross_resale_price != recovered_value
```

Correct accounting:

```text
net_recovery =
    gross_resale
    - marketplace_fee
```

Then:

```text
bounty_asset_cost =
    purchase_price
    - net_recovery
```

RON gas remains a separately denominated execution cost.

---

## 13.4 Inventory-Aware COMBOs

A COMBO should not automatically receive `READY` status.

Execution status must consider:

```text
required_inventory <= available_inventory
```

Otherwise:

```text
status = BLOCKED
shortfall = required_inventory - available_inventory
```
