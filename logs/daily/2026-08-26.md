# 26. Data Architecture Implication

August 26 demonstrates why the AxieOS accounting pipeline must retain individual event types.

A simple net-wallet model would incorrectly combine:

```text
reward
burn
stake
restake
claim
pending withdrawal
```

into one balance movement.

The correct model is:

```text
Blockchain transaction
        ↓
economic event classification
        ↓
asset movement
        ↓
income / expense / transfer treatment
```

For example:

```text
Bounty reward        → income
Ascension bAXS burn  → gameplay expenditure
Stake                → asset transfer / no P&L
Restaked reward      → staking income + reinvestment
Claimed reward       → staking income
Terrarium pending    → receivable / pending settlement
```
