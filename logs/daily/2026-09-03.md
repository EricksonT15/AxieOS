# 11. Backfill Safety Rule

The correct engineering sequence is:

```text
recover source evidence
        ↓
classify completeness
        ↓
audit session model
        ↓
create canonical session linkage
        ↓
write snapshot
        ↓
validate
```

Not:

```text
find historical number
        ↓
insert directly into database
```

This prevents valid historical values from being attached to incorrect session metadata.
