# Capital Preservation Strategy

ETH operating capital is currently treated as a scarce resource, while Fortune Slips replenish daily.

Instead of consuming the purchased 15 Regular Choco:

```text
Buy 15 Choco
→ Complete purchase task
→ Relist 15 Choco
→ Attempt to recover ETH capital
```

Regular Choco for feeding was generated using Fortune Slips:

```text
Fortune Slips
→ Open Regular Pouches
→ Receive Regular Choco
→ Feed Choco
```

This preserves ETH liquidity while consuming a resource that replenishes every day.

# Strategic Insights

## Resource Scarcity

AxieOS should distinguish between different resource types:

```text
ETH            = scarce operating capital
Fortune Slips  = renewable daily resource
RON            = blockchain operating resource
Choco          = consumable inventory
Axies          = recoverable marketplace capital
```

The economically optimal decision may therefore differ from the decision that simply minimizes total resource usage.

---

## Multi-Task Completion

Two important combinations were demonstrated today.

### Marketplace Combo

One Plant Axie purchase:

```text
Task 2 = 200 BP
Task 6 = 650 BP
Total  = 850 BP
```

### Feeding Combo

One 10-Choco feeding:

```text
Task 3 = 200 BP
Task 4 = 160 BP
Total  = 360 BP
```

Future Bounty optimization should actively search for these overlaps.

---

## VRF Cost Optimization

The true cost of pouch opening should not be measured using only the upfront VRF estimate.

AxieOS should track:

```text
Initial VRF payment
+ user network fee
- VRF refund
= actual net pouch-opening cost
```

August 8 provides the first real baseline for this analysis.
