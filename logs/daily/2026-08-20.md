# 18. API Security Model

The transaction extraction workflow uses only:

```text
GET
```

requests.

These are read-only blockchain queries.

The API workflow does **not** require:

* Seed phrase
* Private key
* Wallet password
* Transaction signing
* Contract approval
* Wallet connection

Only public blockchain addresses are required.
