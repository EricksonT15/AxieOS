# Weekly Operations

This document defines the recurring operational workflow for AxieOS.

---

# Sunday

## Terrarium

- Start Terrarium withdrawal timer (72 hours).

Purpose:

Ensure rewards become claimable on Wednesday.

---

# Monday

## Staking

- Restake AXS staking rewards.

Purpose:

Maximize compounding while keeping financial workflows separate.

---

# Wednesday

## Finance Day

- Claim Terrarium withdrawal.
- Claim Weekly Bounty rewards.
- Stake newly received bAXS.
- Review wallet balances.
- Record weekly financial snapshot.

Purpose:

Centralize all financial operations into a single weekly workflow.

---

# Daily

- Claim Shrine Fortune Slips.
- Complete Bounty Board.
- Record Marketplace transactions.
- Update Terrarium experiment when applicable.
